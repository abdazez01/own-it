# own-it v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build own-it v2 in three stages:
- **v2.0:** live link, template engine, split-flap + glass dashboard, sound, music, screen copies, quests, and 6 games.
- **v2.1:** game pack 1.
- **v2.2:** game pack 2.

**Architecture:**
- The Phase 1 Node helper grows a few commands: `serve`, `wait`, `stop`, `build-round`, `build-screen`, `build-recs`.
- A new browser engine (classic scripts in `assets/engine/`) hosts every game as a template in `assets/games/<id>.js`.
- Claude only writes small data JSON. The helper validates it, obfuscates it, and writes it as `.own-it/data/*.js` globals.
- The page talks to Claude through a loopback server (`serve`), and Claude reacts via a background `wait`.

**Tech Stack:**
- Node 18+ (ESM, `node:test`, zero npm dependencies in `own-it/`).
- Vanilla HTML, CSS, and JS, as classic scripts that work on `file://` and on `http://127.0.0.1`.
- Web Audio, Canvas 2D, and SVG.

**Specs (binding):**
- `docs/superpowers/specs/2026-10-17-own-it-v2-design.md` (product: sections 5–15).
- `docs/superpowers/specs/2026-10-17-own-it-v2-frontend-design.md` (everything visual and audio, plus 12a decisions).
- Visual reference: `docs/superpowers/mockups/2026-10-17-dashboard-direction.html`. Its audio, field, flap, toggle, and press code is approved and may be ported.

## Global Constraints

- Phase 1 constraints still hold:
  - Node ≥ 18, no npm dependencies in `own-it/`.
  - Each CLI command prints one line. Errors print `own-it: <msg>` and exit 1.
  - Stored paths are POSIX and relative to the project.
  - Look ids up with `Object.hasOwn`.
  - Validate before any write.
- **Everything the game creates lives in `.own-it/`.** Nothing is written outside it, except moving answer files out of Downloads.
- **Browser code** uses classic scripts only (no ES modules, no `fetch` of local JSON in file:// mode), has no network access except the local serve origin, and never uses `innerHTML` with data. It builds the DOM with `textContent` and `setAttribute`.
- **Dark only.** Tokens come exactly from frontend spec §2.1 ("Graphite gold"), and all text meets WCAG AA on its backing.
- UI copy is sentence case with no em or en dashes. Uppercase appears only inside flap tiles.
- **Sound.**
  - Every sound is synthesized, with no audio files.
  - The master gain is 0.45 into a compressor at −24 dB, 3:1.
  - Clacks are rate-limited to one per ≥55 ms.
  - Sounds use choke groups.
  - Sound effects and music both default to on. Audio starts on the first gesture.
- **Music.**
  - Key: C major. Progressions A = C G Am F and B = F G Em Am.
  - Bars of 4.0 s on an eighth-note grid, no detune, and the 8-section build-up and strip-down loop with fades and a turnaround, exactly as frontend spec §4.3.
- `prefers-reduced-motion` and `prefers-reduced-transparency` are honored as the frontend spec §2.7 and §2.1 describe.
- **Questions** may never have a function name, variable name, config key, or line number as their subject or answer.
- **Token budgets:**
  - quiz round ≤ 3,000 tokens,
  - screen rebuild ≤ 8,000 tokens,
  - session ≤ 15,000 tokens excluding extraction,
  - zone extraction ≤ 30,000 tokens.
- **Commit trailer:** `Co-Authored-By: <your model> <noreply@anthropic.com>`.

**Rulings made at plan time (user asleep, so no downloads):**
- **Fonts.** No font files are downloaded. `tokens.css` declares `--f-flap: "IBM Plex Mono", ui-monospace, Menlo, Consolas, monospace` and `--f-ui: "Geist", system-ui, "Segoe UI", sans-serif`, and uses `local()` faces only. `assets/fonts/README.md` says how to vendor the OFL files later. *Cost if wrong:* system fonts on machines without those faces.
- **Icons.** The Tabler sprite is not downloaded. A minimal icon set (sound, music, help, close, check, arrow, lock, flag, timer) is drawn as simple inline SVG strokes in `assets/engine/icons.js`, with a note to swap in Tabler later. *Cost if wrong:* a later swap.

## Review Focus

1. **The server is reachable from other sites.** A POST without the token, a wrong `Origin`, a body over 256 KB, or a path outside `.own-it/` must be rejected. Test in Task 4.
2. **A malicious screen copy** containing `<script>`, `on*=`, `javascript:`, `<iframe>`, CSS `url()` or `@import`, or `<form action>` must be stripped or rejected. Test in Task 6.
3. **The page loads with missing data files** (no `recs.js`, no `progress.js`, a stale round file). It must render empty or "building" states, never throw. Test in Task 10 (vm smoke).
4. **Audio contexts:**
   - starting audio before a gesture must not throw,
   - after a mute, no voice may be scheduled,
   - the music scheduler must not drift after the tab is hidden and shown again.

   Test in Task 9 (pure scheduler and settings tests).
5. **`build-round` given ids from another zone, unknown game ids, or answers missing for a question** must refuse with exact messages and write nothing. Test in Task 5.

### Task 4: Live link (`serve`, `wait`, `stop`) + inbox-first `collect`

**Files:**
- Create: `cmd-serve.mjs`, `cmd-wait.mjs`, `cmd-stop.mjs`.
- Modify: `cmd-collect.mjs`, `own-it.mjs` (COMMANDS list).
- Test: `tests/serve.test.mjs`.

**Interfaces** (parent spec §5b-2):
- **`serve [--port 0]`**
  - Binds to `127.0.0.1` on the given port, or a free port when 0.
  - Writes `.own-it/serve.json` as `{port, pid, token, startedAt}`. The token is `crypto.randomBytes(16).toString('hex')`.
  - Prints `{url: "http://127.0.0.1:<port>/game.html?t=<token>", port, pid}`.
  - The process keeps running: when started from the CLI, it spawns a detached child (`--foreground` flag for tests).
- **Routes:**
  - `GET /<path>` serves files under `.own-it/` only.
    - Content types: html, js, css, json, svg, woff2.
    - Paths with `..` or absolute paths get a 404.
  - `GET /state?t=` returns `{versions:{<file>:mtimeMs}}` for `data/*.js`, `recs.js`, `progress.js`, and `screens.js`.
  - `POST /event?t=` takes a JSON body ≤ 256 KB with `type ∈ pick|result|challenge|hint|ask`.
    - It writes `.own-it/inbox/<Date.now()>-<type>.json` and replies 204.
  - Rejection rules:
    - wrong or missing token → 403,
    - non-JSON body → 400,
    - too large → 413,
    - an `Origin` header that is not `http://127.0.0.1:<port>` → 403.
- **`wait [--timeout 600]`**
  - Polls `.own-it/inbox/` every 300 ms for a file not listed in `.own-it/inbox/.seen`.
  - It prints that event as one compact line `{type, ...payload, file}`, records it as seen, and exits 0.
  - On timeout it prints `{"idle":true}`.
- **`stop`:** kills the pid from `serve.json`, deletes that file, and prints `{stopped:true}`. It is idempotent.
- **`collect <id>`:** checks the inbox `result` events for that id first (newest), then falls back to Downloads as before.

- [ ] Write the tests (run serve in-process with `--foreground` on port 0):
  - `rejects POST without token`,
  - `rejects foreign Origin`,
  - `rejects 300KB body`,
  - `blocks ../ path`,
  - `serves game.html`,
  - `state lists versions`,
  - `event lands in inbox and wait prints it once`,
  - `wait idle on timeout 1s`,
  - `collect prefers inbox result`.
- [ ] FAIL → implement → PASS → commit.

### Task 5: `build-round` + rounds in `apply`

**Files:**

- Test: `tests/round.test.mjs`.

**Interfaces:**
- **`build-round <game> <file>`**
  - Validates the input against `assets/games/<game>.schema.json`. All ids must exist in the model zone given by `zone`.
  - Assigns `id = <zone>-<game>-<seq>`.
  - Obfuscates every field named `answer` or `answers` with `core.encode`.
  - Writes `.own-it/data/<id>.js` (`window.OWNIT_ROUND = {...}`) and adds `round:{id, game, zone, rung}` to `session.json`.
  - Prints `{id, est}`.
  - Messages:
    - unknown game → `unknown game "<g>"`,
    - foreign ids → `ids not in zone "<z>": <ids>`,
    - a question missing an answer → `missing answer in questions[<i>]`.
- **Schemas, matching the parent spec §6 game rules:**
  - **quiz:** `{zone, mode, questions[5]:{q, options[4]:{text, why}, answer:0-3, peek?}}`. `why` ≤ 160. The options obey the identifier-only ban.
    - **Identifier-only rule** (reject): a single token containing `_`, `/`, or `.`, or camelCase, or wrapped in backticks. The error is `identifier-only answer in questions[<i>].options[<j>]`.
  - **screen-tour:** `{zone, screen, steps[1-6]:{kind:"chain"|"find"|"role", prompt, element?, choices?[2-4], answer}}`.
  - **guess-the-screen:** `{zone, screens[3-8]:{screen, choices[4], answer}}`.
  - **quests:** `{zone, flow, goal, objectives[2-8]:{text, element}, start}`. Objectives are derived from the flow, so the helper fills in the expected path from model `element.does`.
  - **whiteboard:** `{zone, cards[2-12]}`. The answer edges are derived from the model, as Phase 1 map missions did.
  - **boss-battle:** `{zone, questions[5]:{q, kind:"why"|"malicious"|"structure"|"fails"|"term"}}`. There is no answer, because Claude grades it.
- **`apply` accepts round ids** (`<zone>-<game>-<n>`). It reads the result from the inbox or the answer file, maps the rung through the game meta, and applies the Phase 1 XP rules plus parent spec §15.4:
  - quests: +10 per objective in order, −5 per wrong turn, +50 for a clean run.
  - Rung `none` (teach-back) gives only Curiosity XP.

### Task 6: `build-screen` (sanitizer) + screen fog

**Files:**
- Create: `sanitize.mjs`, `cmd-build-screen.mjs`.
- Modify: `cmd-fog.mjs`.
- Test: `tests/screen.test.mjs`.

**Interfaces:**
- **`sanitize(html) → {html, dropped:string[]}`** is a hand-written tokenizer with an allowlist.
  - **Allowed tags:** `div span p h1-h6 ul ol li a button input label select option textarea table thead tbody tr th td img header footer nav main section article aside form strong em small br hr`.
  - **Allowed attributes:** `class style data-ownit type placeholder value disabled checked selected alt aria-* role colspan rowspan for name`.
  - **`a href`** is kept only as `#`, and `form action` is removed.
  - **`img src`** is allowed only as `data:image/(png|svg+xml|jpeg);base64,...` ≤ 40 KB. Otherwise `src` is removed.
  - **`style`** values containing `url(`, `@import`, `expression(`, or `javascript:` are dropped.
  - **Removed entirely, with their contents:** `script`, `iframe`, `object`, `embed`, `link`, `meta`, `base`, and `style` tags. Inline CSS goes into a single allowed leading `<style>` block that passes the same CSS filter.
- **`build-screen <screenId> <file> --zone <z> --inputs <comma files>`**
  - It runs the sanitizer.
  - **Real-data check:** it rejects emails, UUIDs, hex/base64 runs ≥ 24 chars, and any value from the project's `.env*` files, listing what matched.
  - Every `data-ownit` must be an `element` or `surface` id in the zone.
  - The size cap is 60 KB, and there are at most 8 screens per zone.
  - It writes `.own-it/screens/<id>.html` and updates `.own-it/screens.js` (`window.OWNIT_SCREENS = {<id>: {zone, html, inputs:{file:hash}}}`).
  - It prints `{id, bytes, dropped}`.
- **`fog`:** the per-zone output adds `staleScreens:[ids]`, meaning screens whose input hashes changed.
